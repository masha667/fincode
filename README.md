# ФинКод — Классный режим с Firebase

Система для проведения интерактивных уроков финансовой грамотности в классе с отслеживанием прогресса учеников в реальном времени.

## 📁 Структура файлов

- `teacher.html` — панель учителя
- `student.html` — страница для учеников
- `style.css` — общие стили
- `student.js` — логика игры ученика
- `firebase-config.js` — конфигурация Firebase (нужно заполнить!)

## 🚀 БЫСТРЫЙ СТАРТ

### Шаг 1: Создать проект Firebase (5 минут)

1. Откройте https://console.firebase.google.com
2. Войдите через Google-аккаунт
3. Нажмите **"Create a project"** (или "Add project")
4. Введите название: `finkod` (или любое другое)
5. Отключите Google Analytics (не нужен) → **Create project**
6. Дождитесь создания проекта → **Continue**

### Шаг 2: Включить Realtime Database

1. В меню слева выберите **Build** → **Realtime Database**
2. Нажмите **Create Database**
3. Выберите регион: **eur3 (europe-west)** — ближайший к России
4. Нажмите **Next**
5. Выберите **Start in test mode** (для тестирования)
6. Нажмите **Enable**

### Шаг 3: Получить конфигурацию

1. Нажмите на шестерёнку рядом с "Project Overview" → **Project settings**
2. Прокрутите вниз до раздела **"Your apps"**
3. Нажмите на иконку **</>** (Web)
4. Введите название приложения: `finkod-web`
5. Нажмите **Register app**
6. Скопируйте данные из `firebaseConfig`

### Шаг 4: Вставить конфигурацию в код

Откройте файлы `teacher.html` и `student.js`, найдите строки:

```javascript
const firebaseConfig = {
    apiKey: "YOUR_API_KEY",
    ...
};
```

Замените на свои данные из Firebase.

### Шаг 5: Разместить на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите все файлы
3. Включите GitHub Pages (Settings → Pages)
4. Готово! Сайт доступен по адресу `https://ваш-ник.github.io/репозиторий/`

## 📱 Как провести урок

### Учитель:
1. Открывает `teacher.html`
2. Создаёт комнату → получает код (например, `A7B3`)
3. Показывает код на экране или раздаёт QR-код
4. Нажимает **"Начать урок"** когда все вошли
5. Видит прогресс всех учеников в реальном времени

### Ученики:
1. Открывают `student.html`
2. Вводят код комнаты
3. Вводят имя и выбирают аватар
4. Ждут начала урока
5. Играют!

## ⚠️ Важно: Правила безопасности Firebase

Для тестового режима база данных открыта для чтения/записи. Это нормально для урока, но для постоянного использования настройте правила:

```json
{
  "rules": {
    "rooms": {
      ".read": true,
      ".write": true
    }
  }
}
```

Или более строгие правила для production.

## 🔧 Устранение проблем

| Проблема | Решение |
|----------|---------|
| "Firebase не настроен" | Проверьте `firebaseConfig` в обоих файлах |
| "Комната не найдена" | Проверьте код комнаты, убедитесь что учитель создал комнату |
| Данные не обновляются | Проверьте интернет, обновите страницу |
| Ошибка CORS | Убедитесь что используете HTTPS (GitHub Pages даёт HTTPS автоматически) |

## 📞 Поддержка
